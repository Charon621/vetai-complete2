# 报告性能配置与验证

2026-10-10，提示词版本 `vetai-derm-v2.1.0`。本批优化完整报告的预算和输入体积，保留现有规则检索、全部疾病卡、证据状态及直接快路径门槛。

## 请求预算

完整报告默认发送 `thinking_budget=2048` 和 `max_completion_tokens=6144`。前者控制思考长度，后者控制思考与正文总输出；默认留有 4096 token 的正文空间。`max_tokens` 仅限正文，不能当作含思考的总预算；不同时发送 `thinking_budget` 与 `reasoning_effort`。参数依据：[百炼 OpenAI 兼容 Chat 文档](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)，核对日期 2026-10-10。

服务器对完整报告总预算限定在 3072～8192，思考预算限定在 256～4096，且至少为正文预留 2048。异常或缺失参数使用默认值，旧客户端只传 `max_tokens` 时也采用新的默认总预算。预检及问诊继续关闭思考并使用各自的正文上限。不要只改前端配置而忘记服务器限额。

`finish_reason=length` 表示输出未完成，即使内容恰好是合法 JSON，也走结构异常出口，不作为正常报告。不会自动追加一次长请求，避免增加等待和双重开销。既有明确急症升级与独立快路径兜底仍按公共裁决器执行。

## 提示内容

- 保留完整输出字段表、逐图要求、弃答条件、物种和否定边界；2026-10-12 已恢复两份完整示例，覆盖说明、护理、观察条件、就医条件和建议检查，防止只照着局部示例输出简略报告。
- 固定匹配分说明由程序补回，模型只输出空字符串；各栏目保持独立可读，不因其他栏目已有相同事实而省略理由或行动条件。
- 病例与参考资料使用紧凑 JSON；参考来源去重，证据通过 `sourceRefs` 指向 `sources` 数组的下标。
- 每条证据的结论、适用条件、限制、状态和审核角色完整保留；去重来源仍保留来源 ID、标题、URL、页码和章节。没有将 pending 或 partial_support 升级为 source_verified，也没有把资料比对当成兽医签署。

## 本地验证口径

同一批 `evaluation/tools/recall_probe.js` 中的 24 个手写模拟输入，2026-10-10 局部示例方案的历史测量（不代表恢复完整示例后的当前配置）：改动前后提示文本总字符数为 213640 → 166984，减少 21.8%。这是字符数，不是实测 token 或端到端耗时；没有调用真实模型。强命中仍为 12/24，满足抢跑条件仍为 4/24，逐题门槛结果不变。样例已经用于开发，不是独立临床验证。

`tests/report-performance.test.js` 检查压缩后的证据可无损还原、犬猫来源过滤、token 缺失与零值区分、统计不含病例内容、截断报告处理以及独立急症升级。云函数测试检查预算钳制与旧客户端兼容。完整检查仍使用 `npm run audit:evidence`、`npm run eval:retrieval`、`npm test`。

## 运行观察与部署

`modelPerformance` 本地样本记录每次调用的阶段、提示词及知识版本、耗时、输入/输出/思考 token、请求预算、图片数量、输入字符数和截断标记，不新增主诉、照片或身份数据。缺失 usage 记录为 null，不能当作零消耗。开发者埋点导出中包含分版本分阶段汇总及 P50/P95；包括快路径交付后后台完成的完整调用。样本沿用最近 300 条限制，不是全量线上监控，未配置定时上报。

先在微信开发者工具上传并部署 `diagnose` 云函数，再编译预览小程序。云端保留旧提示词版本兼容窗口。部署后使用相同病例输入比较用量、P50/P95、截断率和报告内容；本地 mock 测试不能证明减少思考后质量不变。客户端超时后迟到的响应不重复计数，超时样本的用量可能未知，因此本地统计不能替代账单。若截断增多，先核对实际 reasoning/output usage，再在服务端限额内调整预算。

当前仍为预检与完整报告并行；本次没有增加串行视觉复核请求，照片预检后的检索结果仍主要用于快路径及归因。增加中间复核路径需要同题耗时与输出对照；不能把本批输入压缩结果作为该路径优于并行的证据。

本地知识版本包不含云函数、页面、测试和文档。回退报告性能变更时须同时恢复配套代码并重新部署云函数，不能只恢复知识版本。正式检查记录、源文件备份及交付报告放在仓库外输出目录的 `report-performance-20261010/`。

发布范围核对：相对 `kb-2026.10.09.1`，`utils/api.js` 的逐关判定日志及 `utils/analytics.js` 的快路径漏斗汇总在任务开始前就已随 Git 提交 `6a1fa30` 存在，尚未进入知识版本包。本批保留并明确收录这些既有改动，不将其计为本批性能提升；没有收录 `.DS_Store` 或 `collaboration-web/`。
