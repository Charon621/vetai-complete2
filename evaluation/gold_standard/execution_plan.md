# G1/G2 冻结核心集建立执行计划（v1.0）

## 1. 目标与背景

本文件是把 `benchmark_config.json`（40 例冻结方案、指标体系、泄漏控制）与
`annotation_guide.md`（G1/G2/G3/V1 分层标准、疾病特异证据路径、双盲裁决流程）
落地为可排期、可交付、可验收的操作计划。分层定义、最小证据路径、指标口径等**标准本身
不在此重复**，一律以上述两文件为准；本文件只回答「谁、在什么时间、按什么进入/退出条件、
产出什么」。

范围限定：只覆盖 `core_holdout` 的 40 例 G1/G2 冻结集及其 8 例画质压力变体
（`quality_stress_set`）。`DEV_ONLY` 公开图与 `V1` 数据集参考集
（`../dataset_reference_set/`）不属于本计划，且按 `benchmark_config.json`
的 `does_not_relax`，其存在不放宽本计划任何要求。

当前状态：`benchmark_config.json.status = protocol_only_not_yet_collected`，
即协议已冻结、病例尚未采集。本计划自该状态启动。

约束红线（来自协议，违反即作废重来）：
- 核心集只接受 G1 与 G2，建议 G1 占比 ≥ 60%（`recommended_minimum_g1_fraction`）；
- 划分单位是 `animal_id_hash`（动物），不是图片；同一动物所有就诊与衍生图必须同组同 split；
- 禁止模型自产标签（`model_generated_labels_allowed = false`）；
- 全程单次解盲（`single_final_unblinding`）；看到冻结结果后的任何改动都属于下一版本。

## 2. 角色与职责

| 角色 | 职责 | 隔离要求 |
|---|---|---|
| 项目负责人 | 批准纳排标准、疾病证据路径与高风险判定表；只解盲一次 | 不参与专家标注 |
| 数据管理员 | 病例收集、去标识、分组、证据包完整性核验、清单维护 | 不参与模型评分，不看模型输出 |
| 皮肤科专家 A / B | 独立盲标（见 `expert_annotation_form.template.csv`） | 互不可见；不看模型输出、提示词版本、公开标签 |
| 第三方裁决专家 | 对不一致病例裁决（见 `adjudication_form.template.csv`） | 独立于 A/B，不参与评分执行 |
| 统计负责人 | 运行 `../tools/agreement_stats.py`，出裁决前一致性与置信区间 | 只用锁定标注，不用裁决后标签 |

## 3. 五阶段时间表

预估总周期约 14–20 周（含约 8 周食物排除饮食再激发等长病程病例的天然等待）。
各阶段串行，但阶段一的长病程病例收集可与后续阶段并行滚动。

### 阶段一：病例收集（约 4–8 周）

- **负责人**：数据管理员，负责人审核纳排。
- **进入条件**：疾病特异证据路径与高风险判定表已由负责人+三名专家批准并冻结。
- **要点**：
  - 目标分层严格对齐协议：犬 24 / 猫 16；感染或寄生虫 16、过敏或免疫 9、
    肿瘤/深部/高风险 7、正常或良性模拟物 8；每例 2–4 张日常手机原图。
  - **G1 来源**：具备病原学/组织学等确认路径的病例——真菌培养或经验证 PCR、
    深层皮肤刮片检出螨、细胞学+药敏、代表性活检组织病理并经病理与皮肤科专家复核。
    优先收集 G1 以满足 ≥ 60% 目标。
  - **G2 来源**：无单一决定性检查但完成排除流程、规范挑战/治疗反应与随访、
    双专家一致的复合确认病例（如犬特应性皮炎、食物不良反应需 ≥ 8 周排除饮食+再激发复发、
    马拉色菌相关皮炎的细胞学+治疗反应时间线）。
  - **入选把关**：证据链可追溯、关键日期齐全、专家可定 G1/G2；每例形成完整病例证据包
    （病史、原始报告、采样日期、病程、治疗前后时间线、书面同意）。
  - 从核心病例中预选 8 例登记为压力变体母本，记录 `derivative_group_id`。
- **退出条件**：候选病例数 ≥ 48（40 目标 + 冗余），各分层均有足量候选，
  每例证据包字段可支撑定级；负责人确认候选池分层可达标。

### 阶段二：去标识处理（约 1–2 周）

- **负责人**：数据管理员。
- **进入条件**：候选池通过阶段一退出条件。
- **要点**：
  - 生成不可逆 `animal_id_hash`、`institution_id_hash`；同一动物所有图与就诊归同一哈希。
  - 剔除或遮蔽水印、病历号、主人/工作人员面部等直接标识；禁止使用模型生成或美化图。
  - 排除诊疗操作后拍摄且足以暴露答案的图片。
  - 制作 8 例画质压力变体（适度模糊/曝光不足/裁切不全/压缩），保留母本
    `animal_id_hash` 与 `derivative_group_id`，**不计入 40 例分母**。
- **退出条件**：`deidentified_verified = true` 与 `consent_verified = true` 全部核验通过；
  相似图与来源筛查（`similarity_and_provenance_screen_required`）完成，无泄漏风险病例进入冻结候选。

### 阶段三：双盲专家标注（约 3–4 周）

- **负责人**：皮肤科专家 A、B 独立进行；数据管理员发包。
- **进入条件**：去标识核验通过；管理员仅向专家提供图片与允许的病例字段（不含最终标签）。
- **要点**：
  - 两名专家读**相同证据包**，各自独立填写 `expert_annotation_form.template.csv`：
    主要病因标签、可接受次要标签、G 层级、紧急度、可见形态词、图片质量 0–2、
    证据摘要、0–100 主观把握度。
  - 二人互不可见，且不得看到模型输出、提示词版本、公开来源标签。
  - 两份标注**锁定后**方可计算一致性；严禁先讨论再补填「独立」答案。
- **退出条件**：每例均有 A、B 两份已锁定标注并带时间戳；统计负责人用
  `agreement_stats.py` 算出裁决前一致性（见 §5）。

### 阶段四：第三方裁决（约 1–2 周）

- **负责人**：第三方裁决专家；统计负责人配合。
- **进入条件**：两份标注已锁定，裁决前一致性已计算并留存。
- **要点**：
  - 仅对主要病因、G 层级或紧急度不一致的病例裁决；裁决专家查看两份锁定结果+原始证据，
    填写 `adjudication_form.template.csv` 写出结论与理由（**非简单多数投票**）。
  - 两名专家均不接受的病例升级为排除（`escalated_to_exclusion`），记 `exclusion_reason`。
  - 永久保留两份原始标注、时间戳、裁决记录与最终标签；任何修订产生新版本、不覆盖旧值。
- **退出条件**：所有不一致病例均有裁决记录；最终 G1/G2 病例数 ≥ 40 且分层达标，
  否则回阶段一补收（不得降低标准凑数）。

### 阶段五：冻结发布（约 1 周）

- **负责人**：项目负责人 + 数据管理员。
- **进入条件**：最终标签集完整，达 §5 全部验收标准。
- **要点**：
  - 汇总为 `case_manifest.csv`，全部标 `split = frozen_test`、`gold_status = frozen`。
  - 冻结集标签与模型结果分属不同角色保管；正式运行前只向执行者提供图片与允许字段。
  - 记录冻结版本号与不可变声明；此后仅可解盲一次。
- **退出条件**：版本号签发、清单校验通过、负责人签署冻结确认；进入下游全量评测（依赖任务）。

## 4. 产出物清单

- **`case_manifest.csv`**：核心清单，基于 `case_manifest.template.csv` 逐字段填写
  （`case_id`、`animal_id_hash`、`gold_tier`、`split`、`derivative_group_id`、
  `final_label`、`high_risk_flag`、`photo_quality_score` 等），一例一行 + 8 变体行。
- **`expert_annotations/`**：每名专家每例一份，命名
  `{case_id}__{annotator_id_hash}.csv`，格式同 `expert_annotation_form.template.csv`；
  锁定后只读。
- **`adjudications/`**：每个被裁决病例一份 `{case_id}__adjudication.csv`，
  格式同 `adjudication_form.template.csv`。
- **`agreement/`**：`agreement_stats.py` 输出的裁决前一致性报告（原始一致率、
  Cohen's κ、Gwet's AC1、加权 κ、Wilson 95% CI）。
- **冻结集版本命名**：沿用 `benchmark_id = vetai-dermatology-reference-v1` 前缀，
  冻结集记为 `vetai-derm-core-v1.0.0`（`major` 变更=重新采集/换动物、
  `minor`=新增分层不改旧例、`patch`=纯元数据/去标识修订）；
  解盲后任何改动一律升 `major` 并另建未接触过的新冻结集。

## 5. 验收标准

1. **规模与分层**：恰好 40 个 G1/G2 病例（40 只不同动物），犬 24 / 猫 16，
   四个临床组 16/9/7/8 全部达标；另有 8 例压力变体且未计入分母。
2. **G1 比例**：G1 占比 ≥ 60%（`recommended_minimum_g1_fraction = 0.6`）；
   G1 与 G2 在报告中分层展示。
3. **标注一致性**：用 `agreement_stats.py` 计算**裁决前**一致性——名义变量报
   raw percent agreement + Cohen's κ + Gwet's AC1，紧急度等有序变量报加权 κ。
   κ 与原始一致率必须同时判读（避免高一致率+近 0 κ 的基线患病率假象，
   见 `agreement_stats.py` 头注示例）。目标主要病因 Cohen's κ ≥ 0.6（实质一致）为放行线；
   低于阈值须复盘标注指南与本体后重标，不得靠裁决强行拉平。
4. **区间报告**：每个分层指标报分子/分母 + Wilson 95% CI，禁止只报总体百分比；
   bootstrap 以 `animal_id_hash` 为聚类单位，压力变体走同病例配对分析。
5. **可追溯性**：每例证据链、去标识、同意核验、来源与许可齐全；无禁止用途图片进入冻结集。
6. **冻结后不可变更**：`split = frozen_test` 且 `gold_status = frozen` 后，
   保留裁决前标注与全部时间戳；任何后续改动只能产生新版本、不得覆盖旧值、不得二次解盲。

## 6. 风险与应对

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 病例不足或分层不齐 | 阶段一候选 < 48 或某临床组/物种缺口 | 提前启动长病程病例（食物排除饮食、治疗反应型 G2）滚动收集；多机构协作扩源；宁可延期不降标准凑数 |
| G1 占比不达 60% | 阶段四统计 G1/(G1+G2) < 0.6 | 定向补收有确认检查的病例（培养/PCR/组织病理）；确无法达标则在报告中显著标注并留作下一版本改进项，不得把 G2 谎报为 G1 |
| 专家分歧率过高 | 裁决前 Cohen's κ < 0.6 或大量维度不一致 | 复盘 `label_ontology.json` 与证据路径歧义点，澄清后重标（不可看模型答案后改标准）；必要时增第三名标注者算 Fleiss κ 定位系统性分歧 |
| 数据泄漏 | 图片疑被基础模型训练见过 / 曾用于提示词/few-shot/KB | 记为潜在泄漏并排除；相似图与来源筛查前置到阶段二；核心集与开发集物理隔离 |
| 去标识不彻底 | 残留水印/病历号/面部 | 阶段二双人核验 `deidentified_verified`；发现即回退处理，未通过不得进入标注 |
| 无合格专家/裁决者 | 缺两名皮肤科专家或独立裁决者 | 该批数据只能标为「预试验」，禁止称最终参考标准（协议 §6 硬约束） |
| 解盲后想改标准 | 看到评测结果后提出修改分层/阈值 | 一律作为下一版本，另建未接触过的新冻结集；当前版本冻结不动 |
