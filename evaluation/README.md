# VetAI 评测工具与数据

工程评测用于验证检索、作用域、证据引用和输出边界。合成题目、公开开发图与真实病例分别记录来源；工程命中率不等于临床诊断准确率。

## 日常使用

- `npm test`：应用、检索、标注及知识运营回归。
- `npm run audit:evidence`：核查证据绑定、来源定位、审核记录和卡片变更。
- `npm run eval:retrieval`：在同一批独立维护的题目上比较规则、BM25、混合检索，报告每题及各场景差异。
- `npm run knowledge:status`：检查版本、证据覆盖和当前文件是否偏离发布记录。

评测题位于 `datasets/retrieval_scenarios.json`，覆盖常见问题、口语、否定、多部位、冲突与信息不足。题库独立于实现和原有24例探针维护；本批为合成工程用例，答案由本次实现者编写，未经过独立专家标注。运行后记录开发接触情况，不声称从未见过或临床代表性。

## 可复用资料

`reference_data/` 保留受控标签本体、标注表、病例来源清单及可选的标注校验配置。没有固定样本量或专家招募作为工程发布前提。`validate_annotations.py --mode draft` 对缺项告警；`--mode strict` 在需要正式评分时检查字段完整性。标注修订升版本，保留原始记录。

`tools/` 保留一致性统计、重测、首次计划尝试记账、病例分组及输出评分工具。有病例级临床证据时才计算对应临床指标；缺失的指标显示不可评定，不用工程题目的结果替代。

## 公开开发图

`pilot_public_images/` 的8张图片仅用于格式、画质和流程开发。来源为 Hwang 等人的 Mendeley Data 数据集，DOI `10.17632/5dbht54kw7.1`，许可 CC BY 4.0。来源、许可、处理记录及哈希见该目录 `manifest.csv`。公开宽泛标签不作为已审核的临床参考标签。

## 记录与输出

每次运行记录题库、知识库、检索策略及输入哈希，输出逐题结果、失败情况和分层统计。相同来源或动物的衍生数据同组计数。版本可以反复评测，修订记录原因；禁止只保留最好的一次结果。

源代码、测试和运行必需的知识数据留在仓库。生成报告和版本包放在仓库外，位置见 `docs/knowledge-operations.md`。
