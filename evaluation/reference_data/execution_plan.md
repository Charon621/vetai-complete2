# 参考资料维护流程

本目录为可选的病例标注工具，不规定采集规模和工程上线条件。

1. 记录资料来源、同意与去标识情况；区分公开素材、合成题和临床病例。
2. 有病例级证据时填写清单与实际标注记录；缺少资料时保留空值，不补造诊断。
3. 用 draft 模式检查草稿；需要计算临床参考指标时，用 strict 模式核查所需字段。
4. 有标注意见冲突时保留各方意见及实际裁决结果。
5. 任何修订记录版本、修改原因及审核人；同一来源和动物的资料保持同组。
6. 运行评测时记录输入、算法、知识与标签版本，允许重复比较并保留全部运行。

知识库发布、监控与回退流程见 `../../docs/knowledge-operations.md`。
